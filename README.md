# Project with Openai and Qdrant 🚀

A chat bot that works with customers.

First, enter the OpenAI key and Qdrant key in env, and then run the following command:

## Installation

```bash
git clone git@github.com:Anvar571/open-ai.git
cd open-ai
pnpm i
```

### Run in dev mode

```bash
pnpm start:dev
```

### Run in prod mode

```bash
pnpm start:prod
```
